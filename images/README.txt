CARA PAKAI FOLDER INI (VERSI SIMPEL - SATU FOLDER SAJA)
=========================================================

1. SEMUA foto langsung ditaruh rata di folder "images/" ini.
   TIDAK PERLU dipilah per kategori, tidak perlu bikin subfolder.
   Contoh isi folder:
     images/photo_1204@15-11-2023_16-11.jpg
     images/photo_1205@15-11-2023_16-12.jpg
     images/photo_1830@02-04-2024_09-03.jpg
     ... (ribuan file lain, rata semua)

2. JANGAN ganti nama file. Biarkan persis seperti nama asli
   hasil export Telegram.

3. Kategori (Pakaian Atas, Pakaian Bawah, Kerudung, Aksesoris)
   akan ditentukan otomatis oleh AI di dalam KODE-nya
   (berdasarkan nama/teks produk), BUKAN berdasarkan folder
   tempat file itu berada. Anda tidak perlu memilah apa pun.

4. Kalau ada foto yang belum sempat dipindah, website akan
   otomatis menampilkan kotak placeholder rapi sampai file
   aslinya Anda taruh di folder ini dengan nama yang cocok.

5. Struktur project lengkap:
   dukion-shop/
   ├── index.html      <- file utama website (dari AI)
   └── images/         <- SEMUA foto rata di sini, tanpa subfolder
